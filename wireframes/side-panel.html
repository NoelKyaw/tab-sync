Tab Sync: Side Panel Wireframe

Black-and-white wireframe of the Dia side panel. The panel is identical in every window. Pinned items are shared across windows. Each window sees its own tabs first, then the other windows. All data stays local.

  1. Search covers open tabs in all windows, pins, and local history. Opens with ⌘K.
  2. Pinned is shared across all windows and stored locally. Tiles show ● here, ◐ in another window, ○ not open. Click: if open here, switch to it. If open in another window, bring it here. If not open, open it here. Only one live copy ever exists.
  3. This window is always listed first. The active tab is inverted (black).
  4. zz marks a sleeping tab: the browser has unloaded it to free memory. Clicking it reloads it.
  5. Other windows are collapsible groups. "Bring all here" merges that window's tabs into this one.
  6. Recently closed comes from the browser's own list (no extra storage). "History" opens the local history list.
  7. Footer: counts and settings (auto-sleep timer, history limit).

    Go ↗ switches to the tab in its own window.
    Here ⇣ moves the tab into this window. This is the Arc-style "the tab comes to you."
  2. Right-click has the full set of actions. Pin to all windows adds the tab's URL to the shared Pinned list.
  3. Pinned as a list (alternative to the grid in frame 1) puts the "where is it open" state in text. Pick one: grid or list.
